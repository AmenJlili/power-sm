PowerSM add-in for SOLIDWORKS

URL: https://github.com/AmenJlili/power-sm
Bugs and questions: https://github.com/AmenJlili/power-sm/issues

Installation

Close SOLIDWORKS, then run setup_x64_1.5.exe (administrator rights required).
If an older version of PowerSM is installed, uninstall it first from
Windows Settings > Apps.

Usage

1. Launch SOLIDWORKS.
2. Go to Tools > Add-ins and enable PowerSM (check Start Up to load it every time).
3. With no document open, use the PowerSM > Power Geometry Tool menu.
4. Browse for the source folder, check the parts, enter the new radius,
   thickness and/or bend zone value, then click Start.
   Leave a value empty to keep it unchanged.

Note: the PowerSM menu only appears in a SOLIDWORKS session with no active document.

Requirements

SOLIDWORKS 64-bit, .NET Framework 4.5 or later.
